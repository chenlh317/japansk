依据本集已收录的艺术家与作品的整体气质，以下是可能合口味的延伸推荐。 分组与本书原有的「By artist / By opus / By type」体例呼应。每条仅给出 艺术家・曲名与简短的关联说明；如需正式收录，请按 add-song 流程补充 https://www.uta-net.com/song/<id>/ 链接与歌词正文。

昭和歌謡・アイドル路線#

与 山口百恵・岩崎宏美・河合奈保子・柏原芳恵・小柳ルミ子・酒井法子・ 中森明菜・薬師丸ひろ子 等同温层。

太田裕美 ―「木綿のハンカチーフ」#

筒美京平・松本隆コンビ的代表作之一，男女对白式叙事，与柏原芳恵 〈春なのに〉同属「青春送别」一脉。同作者还可听〈赤いハイヒール〉 〈九月の雨〉。

松田聖子 ―「赤いスイートピー」#

松本隆作詞・呉田軽穂(松任谷由実)作曲，与已收录的松任谷由実 〈真夏の夜の夢〉系出同源。延伸：〈SWEET MEMORIES〉〈瑠璃色の地球〉 (与中森明菜版可对照)。

桜田淳子 ―「わたしの青い鳥」#

阿久悠・中村泰士的早期偶像歌路，与岩崎宏美〈小指の想い出〉一类 七十年代少女歌的甜美哀愁。

八神純子 ―「みずいろの雨」#

声线宽广、转音明亮，与河合奈保子的中后期路线接近。延伸：〈ポーラー スター〉〈思い出は美しすぎて〉。

五輪真弓 ―「恋人よ」#

钢琴叙事抒情歌的范本，气质上介于中島みゆき与岩崎宏美〈聖母たちの ララバイ〉之间。

ちあきなおみ ―「喝采」#

「想い出のレコード」式叙事歌的源流之一，本集已有薬師丸ひろ子翻唱的 〈黄昏のビギン〉，原唱版本同样值得一听。

由紀さおり ―「夜明けのスキャット」#

スキャット唱法的代表作，与岩崎宏美的「歌唱性」气质相通。

小坂明子 ―「あなた」#

七十年代少女自作自唱的代表作，与高田みづえ〈私はピアノ〉同属 「钢琴前的告白」类型。

演歌・正統派#

与 石川さゆり・森昌子 的路线对应。

美空ひばり ―「川の流れのように」#

战后流行歌的总结之作，与岩崎宏美〈愛燦燦〉同为「人生歌」典范。

都はるみ ―「北の宿から」#

阿久悠・小林亜星，与石川さゆり〈津軽海峡・冬景色〉同样是「北国 冬天 + 女性叙事」的范本。

八代亜紀 ―「舟唄」#

阿久悠・浜圭介。本集若已收〈津軽海峡・冬景色〉〈越冬つばめ〉， 同期听〈舟唄〉〈雨の慕情〉可补完「酒・港・雨」的演歌意象群。

藤圭子 ―「圭子の夢は夜ひらく」#

宇多田ヒカルの母。低音域的歌谣ブルース，与中森明菜后期作品(〈難破船〉 〈LIAR〉)的暗调有共鸣。

フォーク・シンガーソングライター#

与 中島みゆき・さだまさし・五輪真弓・松任谷由実・村下孝蔵・久保田早紀・ 高田みづえ 同温层。

井上陽水 ―「少年時代」#

夏天与回忆的代表曲，与さだまさし〈秋桜〉、村下孝蔵〈春雨〉同属 四季抒情的轴心。延伸：〈夢の中へ〉〈氷の世界〉。

風(伊勢正三)―「なごり雪」「22才の別れ」#

七十年代日本フォーク的金字塔，与久保田早紀〈異邦人〉同时期、同氛围。

かぐや姫 ―「赤ちょうちん」#

与本集 uta 章节里的〈神田川〉同作者(南こうせつ／喜多條忠)。可与 〈神田川〉相互参照。

因幡晃 ―「わかって下さい」#

「便箋に綴る」式的告白歌，与中島みゆき〈わかれうた〉相邻。

オフコース(小田和正)―「さよなら」「言葉にできない」#

本集若钟意さだまさし的叙事抒情，可补这条更都市化的脉络。

谷村新司 ―「昴」「いい日旅立ち」#

本集已收 テレサ・テン 翻唱的〈昴〉与山口百恵〈いい日旅立ち〉， 原唱(アリス／谷村)值得对照。

ニューミュージック・シティポップ#

与 松任谷由実・竹内まりや(薬師丸ひろ子翻唱多首所属作家) 同温层。

竹内まりや ―「元気を出して」「プラスティック・ラブ」「駅」#

〈駅〉中森明菜版已收；竹内本人版与原作者意图差距很大，值得对照。 延伸：〈シングル・アゲイン〉(已在 uta 章节)的姊妹作〈駅〉。

大貫妙子 ―「都会」「4:00AM」#

与松任谷由実早期同属「シュガー・ベイブ」血统，氛围更为冷冽。

山下達郎 ―「さよなら夏の日」「クリスマス・イブ」#

与竹内まりや系的城市抒情对位，「夏の終わり」主题与松任谷〈真夏の夜の夢〉 共鸣。

杏里 ―「オリビアを聴きながら」#

尾崎亜美作詞作曲，与河合奈保子〈ハーフムーン・セレナーデ〉一脉。

EPO ―「音楽のような風」#

「土曜の夜は××」型轻盈节奏，可作松任谷由実中期的延伸。

中島みゆきカバー / 提供曲の本歌#

中島みゆきは本集既収。她为他人提供的歌、以及他人翻唱她的版本：

研ナオコ ―「あばよ」「かもめはかもめ」#

中島みゆき提供曲的两首代表作。

工藤静香 ―「慟哭」「めちゃくちゃに泣いてしまいたい」#

中島みゆき作詞作曲，气质与〈悪女〉〈LIAR〉(明菜)共振。

杉本彩 ―「Bad Girl」(中島みゆき作品)#

如喜欢〈悪女〉的姿态可一听。

アニメ・ゲーム・ビジュアルノベル#

与 monogatari / higurashi / school_days / white_album_2 / love_hina / gundam_seed / evangelion / haruhi 等章节同温层。

Lia ―「鳥の詩」「Light colors」「My Soul, Your Beats!」#

本集 uta 已收〈鳥の詩〉。Key 社系列(Air / Clannad / Angel Beats!) 的主题歌群是 white_album_2 / school_days 一带听众的必修课。

川田まみ ―「緋色の空」「悲しみよこんにちは」「Memories Off」#

I’ve(KOTOKO・MELL 同社)系，与〈奈落の花〉〈You〉所在的暗调 ノベルゲー音乐脉络相邻。

KOTOKO ―「Wing my Way」「七転八起☆至上主義!」#

同上 I’ve 系。

茅原実里 ―「雪、無音、窓辺にて。」「優しい忘却」#

〈優しい忘却〉已收(涼宮ハルヒ)。同唱者的個人辑代表作可一并听。

やなぎなぎ ―「ユキトキ」「Vidro模様」#

支倉冬子参与的「白詰草」系作家圈，氛围与〈君の知らない物語〉一脉 相承。

supercell(やなぎなぎ／nagi 期 → こゑだ／chelly 期)―「君の知らない物語」「ホシアイ」「銀色飛行船」#

〈君の知らない物語〉已收；同社团其他曲也值得听。

ClariS ―「コネクト」「irony」「ヒトリゴト」#

魔法少女まどか☆マギカ・俺妹・エロマンガ先生等动画 OP，与〈Magia〉 〈いけないボーダーライン〉同列。

Aimer ―「蝶々結び」「残響散歌」「StarRingChild」#

机动战士ガンダムUC〜鬼灭之刃，与〈君は僕に似ている〉〈焔の扉〉 所在的 Gundam Seed 章节相承。

LiSA ―「紅蓮華」「炎」「oath sign」#

与 fate 系/鬼灭系动画 OP，强烈节奏型的代表。

藍井エイル ―「MEMORIA」「IGNITE」「INNOCENCE」#
